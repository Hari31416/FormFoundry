# FormFoundry Documentation

Welcome to the FormFoundry technical wiki. This documentation is designed to help developers understand, maintain, and extend the FormFoundry platform.

## What is FormFoundry?

FormFoundry is a generalized form-filling and artifact-generation platform. It turns uploaded documents, freeform notes, and conversational answers into a validated case schema and exportable artifacts such as filled PDFs.
