# Backend Documentation

The FormFoundry backend is a high-performance, asynchronous Python API built with FastAPI. It handles the core business logic, AI orchestration, and data persistence for the entire platform.

## Key Sections

- **[Application Initialization](app-initialization.md)**: How the app starts up and configures itself.
- **[Routing](routing.md)**: Details on API endpoints and request lifecycles.
- **[Dependency Injection](dependency-injection.md)**: Managing shared resources like database sessions.
- **[Models](models.md)**: ORM definitions and database schema patterns.
- **[Schemas](schemas.md)**: Pydantic validation and serialization models.
- **[Services](services.md)**: Business logic implementation details.
- **[Database](database.md)**: PostgreSQL, migrations, and session management.

- [Document upload and basic checks](documents.md): Supported Indian documents, API results, and processing adapters.
